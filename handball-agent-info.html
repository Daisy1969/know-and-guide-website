Handball Agent Match — Rules & Tracking

Match Rules

  • Match winner: first agent to accumulate 40 seconds in ACE in the current match.
  • Skill growth: +3% for every 3 seconds an agent spends in ACE (cumulative over watch session).
  • ACE serve rule: any agent in ACE must serve within 3 seconds; otherwise they rotate out to JACK by out/rotation logic.
  • Square ownership labels update dynamically when rank positions change.

Tracking Panels

  • Left panel: current match state, ACE holder, ACE progress.
  • Right panel: per-agent matches won, games played, skill %, recent events.
