Experimental browser feature

Find your way with AI tools

Know & Guide offers three WebMCP tools that let a compatible AI assistant search our public resources, read their indexed content, and open a page for you.

Browser support

WebMCP is a proposed standard and remains experimental. These tools appear only in a supporting browser with WebMCP enabled and an agent that can use it. The website works normally in other browsers.

Chrome offers an origin trial from version 149 and a local testing flag at chrome://flags/#enable-webmcp-testing. This site has no origin-trial token configured, so use an enabled testing browser to try it. Follow the current Chrome WebMCP setup guide for availability and the Model Context Tool Inspector extension.

What your assistant can do

Find a resource

search_knowandguide_resources searches learning material, blog posts, research, apps, support, privacy, projects, and information about Know & Guide.

Try: “Find Year 9 maths lessons on Know & Guide.”

Read public content

get_knowandguide_resource returns a resource’s indexed text. Longer resources can be read in sections. The index is a snapshot of published content, so open the page when you need its full layout, media, or interactive features.

Try: “Read the Paper Fleet Duel support information.”

Open a page

open_knowandguide_resource navigates this tab to a page in our public resource catalogue on the same website.

Try: “Open that lesson for me.”

Public resources, a clear scope

These tools use only our public content catalogue. They do not access admin data, read form entries, submit forms, or perform account actions. They do not control separate apps hosted on Know & Guide subdomains.

The WebMCP integration does not add an AI service, API key, or query analytics. Searching and reading the downloaded catalogue happen in your browser. Your chosen browser, assistant, or inspector may process requests under its own privacy settings.

For developers: try the native API

For Chrome 155 and later with WebMCP enabled, open developer tools on this site and run the following after the page loads. See the official imperative API guide for current syntax.

const tools = await document.modelContext.getTools();
const search = tools.find(
  tool => tool.name === "search_knowandguide_resources"
);
const args = {
  query: "Year 9 maths",
  category: "learning",
  limit: 5
};
await document.modelContext.executeTool(search, args);

In Chrome 153–154, use await document.modelContext.executeTool(search, JSON.stringify(args)) for the last line.

The integration also recognises earlier implementations using navigator.modelContext. Browser APIs and inspector support can change while WebMCP is experimental.
