Cortex OS

An AI-native cognitive computing platform where intelligence is not another application. It is the organising principle of the system.

Read the Cortex Manifesto Explore the research programme
Research proposal

From application-first to intelligence-first computing

Modern operating systems were built around files, applications, and visual interfaces. Cortex OS investigates a different stack: a deterministic foundation supporting multiple specialised cognitive systems that understand intent, coordinate resources, and operate locally whenever practical.

Secure bootloader ↓ Minimal deterministic kernel ↓ Hardware isolation, drivers and resource control ↓ Cognitive runtime and trusted service boundary ↓ Specialist intelligences: system · memory · security · communication · perception ↓ Executive intelligence and human intent

Foundational principles

Intent over applications

The primary computational object becomes the user's objective rather than the software package used to achieve it.

Local autonomy

Specialist subsystems execute domain tasks without forcing the executive intelligence to micromanage every operation.

Determinism below reasoning

Adaptive models propose and coordinate. Verifiable components retain control of memory, scheduling, isolation, safety and hardware access.

Controlled learning

Reasoning may be continuous, but model updates must be observable, auditable, validated and reversible.

Hardware-software co-design

The long-term architecture explores specialist processors, shared memory and high-speed cognitive interconnects.

Voice and context first

Displays become optional windows into the system rather than the centre of the human-computer relationship.
